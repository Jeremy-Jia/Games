# 2.3.0：弧线 3D 乒乓球与叠界方块

日期：2026-10-28（Asia/Shanghai）。真机：小米18 `hongkong`，Android 17。

## 新增玩法

首页改为四宫格：碰界、星隙、弧线、叠界。各自显示纪录，继承碰界首页的浅色／深色外观。新 Activity 均为内部入口，没有新增联网或 Root 权限。

弧线使用三维坐标计算球台、球网、球拍与球的重力和碰撞，用统一透视相机投影绘制球台、网格、阴影、球路拖尾。左右拖动控制球拍，自动接击，快速横移影响回球落点；三档 AI；11 分且领先 2 分获胜；轮换发球并自动进入下一分。采用街机规则，发球擦网计失误，未实现正式比赛的擦网重发。

叠界使用 10×20 棋盘、7 袋随机、SRS 旋转踢墙、暂存、影子落点、软降／直落、锁定延迟、连消和逐级提速。按钮支持长按移动，棋盘支持横滑移动、轻点旋转、下滑直落与上滑暂存。

两款新游戏均提供暂停、音效、触感开关和独立纪录。失焦或后台时停止模拟和前台反馈；回到游戏后由玩家继续。仅保存纪录与设置，没有新增跨进程的整局比赛／棋盘存档。

## 引擎回归

`test.ps1` 四套引擎测试全部通过，原碰界与星隙回归继续运行。

- 乒乓球：三维合法发球、台面反弹、过网与回球、球网／出界／二次落台判分、连续回合、11 分及加分赛、AI、确定性回放、无效步长与重置。
- 方块：100 组 7 袋种子、I/T 墙踢和地板踢、暂存限制、落点与直落、单／多行消除、连消／连续四行加分、锁定延迟与重置次数上限、暂停、封顶、确定性回放。
