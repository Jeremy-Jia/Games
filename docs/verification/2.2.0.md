# 2.2.0：密集砖阵、反弹障碍与最终 Boss

验收日期：2026-10-28（Asia/Shanghai）。设备：小米18，代号 `hongkong`，型号 `M610BB`。

## 本次行为

- 砖阵使用 16–18 列、12–14 行，按图案保留部分空隙；180 组样本包含 184–249 块可破坏砖，单砖最多约 51×30 逻辑单位。
- 每关加入 1–3 个独立反弹障碍。它们改变普通球与彗星球的方向，不增加消除目标、不产生得分、不被道具消除。奖励球的生成与补充会避开障碍和其他奖励球。
- 星隙按本波击破目标推进，不使用时间判定胜利。奇遇四波目标为 12、18、24、30；普通模式六波目标为 18、24、30、36、42、48。清空全部普通波次后才生成最终 Boss，击败它才获胜。
- 最终 Boss 在奇遇／普通模式的生命分别为 2400／4800；低于 40% 后加强旋转弹幕和瞄准攻击。升级、冲击波、移动和敌人预警保留；奇遇自动升级、自动结算返回。

## 引擎验证

`test.ps1` 两套回归通过，涵盖：

- 180 组小砖布局；最小画布与高挡板条件下的障碍间隙；普通球及彗星球反弹；障碍不影响清关。
- 540 组高度、挡板、随机种子的奖励球避让，包含初始和补充生成。
- 360 组神秘砖随机位置与首排避让。
- 障碍与原局完整快照、重复奖励、取消与最后一砖清关。
- 击破目标推进、时间超过旧上限仍不自动胜利、最后才出现 Boss、胜利与失败终局、自动升级不丢失转向、实体数量上限。

另用真正的 2.1.0 引擎写出 V1 快照，再由新版读取，原关卡、分数和砖阵保留，新增障碍列表按空集合处理。旧局面不会被强行替换为新砖阵；下一关或重新开始使用新布局。

`BalanceProbe challenge` 的 16 个固定种子，在指定绕圈驾驶和主动脉冲条件下，均通过四波与 Boss，耗时约 48.2–62.9 秒。模拟没有修改生命、伤害或时钟。这个范围是指定驾驶的实测用时，不是游戏时间限制，也不代表所有玩家都会获胜。

## 小米18完整往返

手机原先安装碰界 1.3.0。验证签名一致后以覆盖安装升级，测试前另备份游戏偏好。系统拦截单独测试包安装，因此使用 `selfTest` 变体内置同一个 Instrumentation；测试结束后再覆盖回不含测试入口的 Release。

测试通过真实 Activity、实际绘制时钟和正常战斗执行。驾驶只提供转向目标和释放充好的冲击波，不改生命、伤害、敌人血量或游戏时间；神秘砖入口采用引擎命中驱动，碰撞反弹另由纯 Java 回归覆盖。

确认结果：

- 进入真实新砖阵，存在密集砖块及障碍；击中神秘砖后自动打开星隙。
- 波次持续推进，超过旧的 30 秒后继续战斗，最终 Boss 被正常攻击击败。
- 奇遇中没有升级选择窗；结算、领奖、返回和继续均不需要点击。
