# SIX GAMES 2.5.0：五款随机目标奇遇

日期：2026-10-28（Asia/Shanghai）。真机：小米18 `hongkong`，Android 17。

## 最终行为

神秘砖块会等概率选择星隙、弧线、叠界、野径或准星，再分别随机生成指标、目标值、难度和局面种子。每款游戏提供两个指标：

| 游戏 | 指标 0 | 指标 1 |
| --- | --- | --- |
| 星隙 | 击破敌机 | 得分 |
| 弧线 | 赢分 | 最长连续回击 |
| 叠界 | 消行 | 锁定方块数量 |
| 野径 | 行驶距离 | 金币 |
| 准星 | 命中数量 | 得分 |

难度采用几何长尾生成，目标按基础随机值与难度缩放，没有固定档位列表或游戏目标上限；高目标更罕见。目标使用 `long`、难度使用正整数，极端数值做溢出保护，不宣称数学上的无限精度。

奇遇中可持续推进：星隙使用连续波次，乒乓球不在11分结束，打靶不在10发结束。目标栏显示任务、难度和进度。达标后冻结模拟，先保存结果，再自动返回碰界；原局继续打球。失败或主动取消也返回，取消不扣碰界生命。普通首页入口保持原规则，奇遇不写普通纪录。

## 持久化

游戏、指标、目标、难度与种子一起保存到原局 V1 快照，恢复时不重抽。旧快照没有目标时首次生成一次。返回结果核对 ID 及全部目标参数，拒绝错配与重复奖励。完成结果一旦持久化，子 Activity 重建会优先返回该结果，避免重玩或取消覆盖成功。

小游戏的实时运行进度仍不跨进程保存；尚未完成时进程重建会以同一个目标重新开始，不能将“目标不变”理解为每一帧都有存档。

## 回归与生成验证

六款引擎回归及 `EncounterPlanTest` 全部通过。目标生成测试覆盖 60,000 个种子，五款游戏与各自两个指标均被抽中，最高抽到难度20；这只是样本最大值，不是难度上限。另验证同一奇遇身份的结果可复现，以及50亿目标、1000难度的合法表示和精确边界。

引擎新增验证包含星隙超过旧84／198击破预算后仍可继续、乒乓球超过11分、打靶连续28次命中、方块及各进度计数超过32位范围、较大难度数值不导致负数溢出，以及重置普通模式后恢复原规则。

## 五条真机往返

`CollectionSmokeInstrumentation` 通过实际神秘砖命中流程打开子游戏。为可靠覆盖所有分支，五次成功路径使用明确的目标夹具，进度由正常游戏模拟和输入产生，不直接设置成功标志：

```text
PASS route 0 星隙: 击破 6 架敌机, difficulty=1, real progress=6, automatic return and saved ball/obstacle state
PASS route 1 弧线: 连续回击 4 拍, difficulty=2, real progress=4, automatic return and saved ball/obstacle state
PASS route 2 叠界: 放置 3 块方块, difficulty=2, real progress=3, automatic return and saved ball/obstacle state
PASS route 3 野径: 行驶 22 米, difficulty=2, real progress=22, automatic return and saved ball/obstacle state
PASS route 4 准星: 命中 2 个靶, difficulty=2, real progress=2, automatic return and saved ball/obstacle state
PASS unforced random route 1, stable plan, mismatched callback rejected and cancellation
PASS failed encounter auto-return
PASS durable completed-result recovery through recreated child
PASS: all five random-goal portal routes, random selection/cancel/failure, automatic continuation; preferences_restored=true
```

- 星隙模拟驾驶及释放充好的脉冲；乒乓球预测回球位置；方块进行正常移动／直落；赛车提供油门；打靶使用游戏模型补偿瞄准后正常射击。
- 每次比较原球位置与速度、砖块血量、障碍、关卡、生命和计时，检查冻结快照及完整目标保存。
- 完成后不点领奖或继续，确认奖励恰好一次、原局恢复运动。
- 额外进行一次未指定游戏的真实随机选择，检查目标与身份推导一致、错配回调被拒绝、取消自动返回。
- 注入正常致命弹丸驱动失败返回；用真正成功时保存的结果与待完成快照模拟重建窗口，确认结果直接恢复。未做整机进程强杀。
