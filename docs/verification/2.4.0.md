# SIX GAMES 2.4.0：野径登山赛车与准星打靶

日期：2026-10-28（Asia/Shanghai）。设备：小米18 `hongkong`，Android 17。

## 最终行为

- 应用图标名称、系统应用标签与首页标题统一为 **SIX GAMES**，包名和原存档不变。
- 首页增加野径、准星，共六款游戏；两款新游戏横屏，原来四款保持竖屏。
- 野径有双轮弹簧接地、重力、牵引、空中俯仰、连续起伏山路、金币和燃油补给；双指踏板，翻覆或缺油停驶结束，保存距离与金币纪录。
- 准星有 1×／3×／6×变倍、拖动瞄准、按住屏息、后坐力、5 发弹匣和装填；10 发一轮，距离逐步增加，后段为移动纸靶，按环数与连击计分。风偏与下坠为虚构街机游戏数值。
- 两款均在后台／失焦时暂停并释放触控；返回后手动继续。保存纪录与设置，未实现跨进程的实时行驶／打靶存档。

## 引擎与构建

`test.ps1` 六套纯 Java 引擎回归通过。新增覆盖：

- 赛车地形连续性、双轮接地稳定性、油门／刹车、空中姿态、金币／燃油补给、翻覆、缺油停驶、暂停、无效步长与确定性。固定种子的自然全油门模拟在 12 秒行驶约 226 m，未修改车辆位置或生命状态。
- 打靶命中／脱靶／环数、飞行时间、移动目标、弹匣与装填、屏息体力、变倍、暂停、10 发轮次结束、重置与确定性。

`assembleSelfTest`、`assembleRelease` 和 `lintVitalRelease` 通过。正式 APK 不包含 Instrumentation 测试入口。

赛车使用实际踏板触摸并按住，由真实绘制时钟推动车辆；确认燃油下降、取消触摸后油门归零。再次按住油门后，用竖屏首页 Activity 覆盖横屏游戏，检查时钟冻结且踏板清零；返回后点击继续，时钟恢复，退出保存距离纪录。没有修改车辆位置或直接设置结束状态。

打靶使用实际按钮检查变倍、屏息的按下／释放与体力消耗，并以拖动事件验证瞄准变化。实际方向切换与失焦后，时钟冻结且屏息释放；恢复后完成 10 发射击和中途装填，验证每次触摸只消耗一发、实际飞行延迟后结算、移动目标命中、轮次结束及纪录只计一次。完整轮次由测试根据游戏模型生成补偿瞄准输入，并通过真实射击按钮执行；100% 命中是这个测试输入的结果，不代表手动操作难度。

乒乓球与方块也复测通过；相关夹具边界见 [2.3.0](2.3.0.md)。所有测试完毕后恢复原偏好，原碰界第 74 关、最高分 508318、挑战最高分 24442、外观与挡板设置保留。用户实际乒乓球纪录也保留，测试分数不写入最终个人纪录。
